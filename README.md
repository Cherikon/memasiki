# МЕМАСИКИ в браузере

React-версия викторины. В ней 50 вопросов в порядке Steam-версии, оригинальные картинки и звуки ответов, русский и английский тексты и шесть итоговых рангов.

## Запуск на Windows

Нужен Node.js 22.16 или новее. Дважды щёлкните по `play.cmd`, чтобы открыть игру в браузере. Оставьте окно командной строки открытым во время игры.

Для ручного запуска откройте PowerShell в папке проекта и выполните:

```powershell
npm.cmd ci
npm.cmd run import-game
npm.cmd run dev
```

Откройте http://127.0.0.1:5173. Если порт занят, используйте адрес из вывода Vite. Сервер слушает только локальный интерфейс.

Импорт читает `D:\SteamLibrary\steamapps\common\МЕМАСИКИ\MEMASIKI4.dat` и сохраняет игровые ресурсы в папку `public/game`. Для другого пути передайте его явно:

```powershell
npm.cmd run import-game -- 'E:\SteamLibrary\steamapps\common\МЕМАСИКИ\MEMASIKI4.dat'
```

## GitHub Pages

1. Запушьте ветку `main` в свой репозиторий. Файлы `public/game` входят в проект, поэтому сборке на GitHub не нужна установка Steam.
2. Откройте **Settings → Pages** и выберите **GitHub Actions** в разделе **Build and deployment → Source**.
3. В разделе **Actions** запустите **Deploy to GitHub Pages → Run workflow**, если первый запуск прошёл до настройки Pages. Следующие пуши в `main` запустят публикацию автоматически.
4. Скопируйте адрес из **Settings → Pages**. Для репозитория `memasiki` обычно это `https://<имя-пользователя>.github.io/memasiki/`.

Обычный сайт GitHub Pages публичный. Вместе со страницей будут доступны игровые изображения, звуки и тексты, включённые в сборку.

## Управление

Отвечайте мышью или клавишами 1–4. Ошибка снимает один балл до минимума в ноль и оставляет возможность выбрать другой вариант. Правильный ответ даёт один балл и через две секунды открывает следующий вопрос. Esc возвращает в меню.

Веб-интерфейс адаптирован для узких экранов. Steam-достижения и заставка запуска остались в Windows-версии.
